# 随屏 · TaskbarFollow

Windows 11 多屏小工具：在哪块屏幕上点开，窗口就出现在哪块屏幕。

## 能做什么

- **任务栏：** 在屏幕2的任务栏打开或切换应用，窗口就显示在屏幕2，不会跑回主屏。
- **桌面、资源管理器、开始菜单：** 在哪块屏幕上双击打开程序，程序窗口就跟到那块屏幕。
- **应用里弹出的新窗口：** 比如视频软件点剧集后弹出的播放窗口，也会出现在你点击的屏幕。
- **应用里点开的网页（可选）：** 飞书等应用里点开的链接，会在你点击的那块屏幕的浏览器里打开。

## 下载与使用

**下载：** [v0.3.9 便携 ZIP](https://github.com/zhailan7796-boop/wishelp1/releases/download/suiping-v0.3.9/TaskbarFollow-0.3.9-portable.zip) · [更新说明](https://github.com/zhailan7796-boop/wishelp1/releases/tag/suiping-v0.3.9)

1. 下载便携版 ZIP，解压整个文件夹。
2. 双击 **Start.exe**，状态窗口显示「运行中」就可以用了。不用安装，也不需要管理员权限。
3. 关掉状态窗口后，随屏仍在右下角托盘里运行。`Ctrl+Alt+F12` 可以暂停或恢复。

托盘菜单里还能打开或关闭这些功能：

- **连接第二块屏幕时自动启动：** 开机或接上外接屏幕后自动运行。
- **悬停预览随屏：** 鼠标悬停任务栏缩略图时，预览也显示在当前屏幕。
- **应用里打开的链接也随屏：** 见下一节。

## 应用里打开的网页也随屏（可选）

托盘菜单 →「应用里打开的链接也随屏…」，按提示在 Windows 设置里把「随屏链接」设为默认浏览器。Windows 只允许你自己设置默认浏览器，随屏不能代你点。网页仍由原来的 Chrome 或 Edge 打开。

不想用了：双击文件夹里的「撤销链接随屏.cmd」。

## 需要知道的

- 只支持 Windows 11 x64，并且接着两块或更多显示器。
- 以管理员身份运行的程序，随屏可能移动不了它的窗口。
- 少数程序会在打开后把窗口挪回自己记住的位置。32 位程序（如部分视频软件）会先在原来的屏幕出现，再移过来。
- 遇到问题：托盘菜单 →「打开日志」，把 `logs` 文件夹里的日志附在 Issues 里反馈。

## 卸载

1. 如果开过「链接随屏」，先双击「撤销链接随屏.cmd」。
2. 如果开过「连接第二块屏幕时自动启动」，在托盘菜单里把它关掉。
3. 托盘菜单 →「退出」，然后删除整个文件夹。

## 开发者

运行 `build.ps1` 从源码打包，需要 Visual Studio 的 C++ 工具。技术细节在 `docs` 文件夹里。MIT 许可。
