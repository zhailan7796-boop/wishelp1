## 随屏 0.3.8

新增可选的「链接随屏」：飞书等应用里点开的网页在你点击的屏幕打开。应用里弹出的新窗口（如视频播放窗口）和桌面快捷方式打开的程序，也会跟到点击的屏幕。修复两块屏幕缩放比例不同时的几处定位问题。

完整解压 ZIP 后双击 `Start.exe`。升级前请先从托盘退出正在运行的随屏。运行时随包附带，无需另装 AutoHotkey。
